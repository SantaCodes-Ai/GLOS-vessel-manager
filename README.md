
# Global Link Ocean Streams — Vessel Certificate Management System

## 1. Project Overview

This project is a web-based Vessel Certificate Management System developed for Global Link Ocean Streams, a maritime company in Nigeria.

The system aims to replace manual or fragmented certificate management with a centralised application for storing vessel information, managing certificate documents and monitoring certificate expiry dates.

The application was developed as part of the ITNPBD4 Applying Generative AI module at the University of Stirling.

## 2. Technology Stack

- PHP 8.5
- Laravel 13
- Livewire 4
- MySQL 8.4
- HTML, CSS and JavaScript
- Git and GitHub
- Visual Studio Code

## 3. Main Features

- Vessel registration and management
- Certificate types and certificate records
- Certificate PDF uploads and renewals
- Certificate version history
- Certificate expiry tracking and status indicators
- User registration and email verification
- Administrative approval of accounts
- Role-based access control
- Vessel-specific access for authorised staff
- Search and dashboard functionality

## 4. Use of Generative AI

Two AI tools supported the development process.

### ChatGPT — Learn and Plan

ChatGPT was used to explore the initial project idea, identify requirements, evaluate technology choices and understand software development concepts.

The original planning conversations took place in August and October 2026.

### Codex — Create and Evaluate

Codex was used to assist with application implementation, database migrations, Laravel functionality, debugging, automated tests and iterative improvements.

AI-generated outputs were reviewed and tested during development.
